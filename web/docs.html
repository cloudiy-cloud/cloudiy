Everything you need to know about the decentralized GPU network on Solana.

Introduction

GPUaaS is a decentralized protocol that allows anyone to rent or provide GPU compute power securely using the Solana blockchain and USDC payments.

The goal is to create a global, cheap, and censorship-resistant alternative for heavy computation (AI, rendering, model training, etc.).

Architecture

Application Layer
Web Dashboard • Marketplace • Jobs
Network Layer
gRPC / QUIC • TLS • P2P Discovery
Blockchain Layer
Solana + Anchor + USDC Escrow
Execution Layer
Providers (Rust + CUDA/OpenCL)

Protocol on Solana

The protocol uses Anchor programs to manage:

  • • Provider registration
  • • Job creation and execution
  • • USDC payment escrow
  • • Execution verification (future: zk-proofs)

USDC Escrow

All payments are locked in an escrow on Solana. The provider only receives funds after successful job completion (or after timeout/dispute).

Providers

Anyone with a GPU can become a provider. The software is open-source and runs locally.

Consumers

Users can submit jobs through the dashboard or via API.
