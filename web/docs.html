Introduction

Cloudify is a decentralized cloud computing protocol. Its first product is GPU-as-a-Service: anyone can rent or provide GPU compute power securely, with payments settled in USDC on the Solana blockchain.

Providers install a small open-source Rust program with cargo that connects their machine to the network. Consumers discover providers in the web marketplace, submit jobs from the dashboard or CLI, and everything is managed from the browser.

The goal is a global, cheap, censorship-resistant alternative for heavy computation — AI inference and training, rendering, and scientific workloads.

Protocol on Solana

The protocol uses Anchor programs to manage:

  • • Provider registration
  • • Job creation and execution
  • • USDC payment escrow
  • • Execution verification (future: zk-proofs)

USDC Escrow

All payments are locked in an escrow on Solana. The provider only receives funds after successful job completion (or after timeout/dispute).

  • 1. Consumer rents a GPU — USDC is locked in the escrow program (Anchor).
  • 2. Provider executes the job and submits the signed result.
  • 3. On confirmation, the escrow releases USDC to the provider, minus protocol fee.
  • 4. On timeout or dispute, funds return to the consumer.

The escrow program (Anchor) is live on devnet: 9zMBC7JDA8SJ2mk3ATYqRuJvn14MQyZVg9q3XPnzc1TN — instructions create_job, release and refund, with a 4% protocol fee. Pricing is quoted over HTTP via the x402 protocol: nodes respond 402 Payment Required with the USDC price and clients retry with an X-PAYMENT header — no accounts, no API keys.

Providers

Anyone with a GPU can become a provider. The software is open-source and runs locally — install it with Cargo and start earning USDC:

$ cargo install cloudify-provider
$ cloudify-provider serve --token my-secret --gpu-model "RTX 4090"
🚀 Cloudify Provider Node running at http://0.0.0.0:8080
Solana pubkey: GnaU...sFJP

The node exposes a local HTTP API: GET /health, GET /info, POST /submit and GET /status/:job_id. Your Solana keypair (~/.config/solana/id.json) identifies the node and receives USDC payouts.

Consumers

Users can submit jobs through the dashboard, or directly via the CLI / HTTP API:

$ cloudify-consumer submit --server 127.0.0.1:8080 --kernel vector_add --data "1,2,3" --token my-secret
✅ Job a8220a3c… completed!
Result: GPU_RESULT: vector_add executed with input=1,2,3
$ cloudify-consumer status --server 127.0.0.1:8080 --job-id <id>
$ cloudify-consumer info --server 127.0.0.1:8080

Without payment, the node answers 402 Payment Required with its USDC quote (x402). Retry with an X-PAYMENT header (--x402-demo shows the flow) or use the dev token via CLOUDIFY_TOKEN for local testing.
